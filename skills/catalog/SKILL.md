# UI5 Web Components catalog

[The UI5 Web Components](https://ui5.github.io/webcomponents/docs/) project offers a rich set of enterprise-grade, reusable UI elements built on top of the Web Components standards. With UI5 Web Components, developers can leverage a powerful, flexible, and future-proof toolkit to create anything from static web sites to complex web applications.
