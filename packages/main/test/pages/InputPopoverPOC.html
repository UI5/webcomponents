1 — Input at the left (no flip)

Application leaves suggestionsHorizontalAlign="Start" (default).

↳ Dropdown left edge = input left edge

2 — Input at the right edge (flip to End)

Application sets suggestionsHorizontalAlign="End" after detecting the input is in the right half of the viewport.

↳ Dropdown right edge = input right edge

3 — RTL: Input at the left edge (flip to End)

↳ Dropdown left edge = input left edge

4 — RTL: Input at the right edge (no flip)

5 — Input inside a Dialog

The dialog's right-side input sets suggestionsHorizontalAlign="End" via the same application logic.
