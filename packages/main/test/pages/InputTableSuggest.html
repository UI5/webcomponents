Custom Filtering (app-side) - hide/show table rows

The component does not filter internally — it opens with whatever rows are visible. The application decides what to show by toggling each row's hidden property. Type to filter by any column (name, department, or location). Rows that don't match are hidden.

Selected: (none)
Custom Filtering (add-remove table rows)

An alternative to hiding rows: the app keeps a data model and, on every keystroke, removes all rows and recreates only the matching ones — the same pattern ui5-input uses for custom app filtering in Input.html (removeChild loop, then createElement + appendChild). No rows are declared in markup; they are generated from the data array.

Custom Highlighting (app-side)

The component no longer highlights matches itself. Apps can reproduce the effect by wrapping the matched text in <b> via the bundle's generateHighlightedMarkup helper and setting the cell's innerHTML — the same approach used by ui5-input's custom suggestion items. Type to see the matched substring emphasized in every cell.
