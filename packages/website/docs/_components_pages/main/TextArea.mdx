### Max Length
You can use the <b>maxlength</b> and <b>counterMode</b> properties to define characters limit
and to indicates how many characters are remaining before the limit or exceeding after the limit.
Set <b>counterMode</b> to "Always" to keep the counter permanently visible.

<MaxLength />

### Exceeded Text
Set <b>counterMode</b> to "Auto" to show the character counter only when the TextArea is focused
or when the character limit is exceeded. The counter is also always visible when
<b>valueState</b> is "Critical" or "Negative". Space for the counter is always reserved to avoid layout shifts.

The deprecated <b>showExceededText</b> Boolean still works and maps to <b>counterMode</b> "Always".

The application can control threshold-based coloring by setting <b>valueState</b> based on character count.
