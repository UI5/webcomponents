ShellBar - getSearchButtonDomRef() focus across states

Each section resolves the search button via the public getSearchButtonDomRef() method and focuses it - the same single call a shell AccessKeysHandler uses to restore the search shortcut. No shadow DOM traversal is needed. Press Alt+F anywhere to focus the search of section 1 (focus only, the search is not triggered).

1. Search collapsed

Collapsed search toggle is visible in the bar.

2. Search expanded

Search field is expanded; there is no toggle button, so the search input is resolved and focused. (disable-search-collapse keeps it expanded.)
Focus via getSearchButtonDomRef()

3. Search collapsed in overflow

The bar is narrow, so the search toggle moves into the overflow. The method opens the overflow popover and resolves the search entry inside it.
