InactiveSelectable — manual test

Expected: no active press/hover feedback and the item-click event never fires for InactiveSelectable items. But the item can still be selected — via the item body (click / Space / Enter) or the checkbox/radio. Screen reader should not announce the raw "InactiveSelectable" text.
